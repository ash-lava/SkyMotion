SKYMOTION 2.0.2 — UPDATE THE EXISTING RENDER SERVICE

The app is already in the GitHub repository connected to Render.
There is no ZIP to upload and no new repository or Render service to create.

1. REVIEW AND MERGE THE PULL REQUEST
   Open the supplied pull-request link on GitHub.
   Review the changes, then select Merge pull request > Confirm merge.
   This updates main. The branch containing the proposed changes is separate
   from main until you merge it.

2. DEPLOY THE MERGED COMMIT
   If Render auto-deploy is on for main, it starts after the merge.
   Otherwise open Render Dashboard > SkyMotion > Manual Deploy >
   Deploy latest commit. Wait for the deployment to finish.

   Existing commands remain:
   Build: pip install -r requirements.txt && python -m unittest -q test_server.py
   Start: uvicorn server:app --host 0.0.0.0 --port $PORT
   Health check: /api/health

   Keep SPHEREX_COLLECTIONS=spherex_dr1 for the current release selection.
   DR1 deep, QR3, and QR3 deep remain optional documented collections.
   No new Python dependency, API key, or environment variable is needed.

3. CONFIRM THE VERSION
   Open https://skymotion-sk2p.onrender.com/api/health
   Look for version 2.0.2. Hard-refresh the app after it is deployed.

4. TRY A SEARCH
   Choose a suggested target and select Load SPHEREx exposures.
   If SIA fails, the app also tries IRSA TAP. A recovered sequence has a
   compact notice; expand Archive connection details for its coverage limits.
   If both services fail, use Retry archive after a short interval.
   Try another detector when a successful search returns no exposures.

The existing black-and-gold sky atlas and map fallback are preserved.
The color reference atlas uses CDS survey services, independently of IRSA.
A service outage can still prevent images; merging cannot repair an upstream
IRSA/CDS outage. No simulated sky images are served to hide a failure.

See README.md for the API behavior and VALIDATION.txt for verification limits.
The older MAP_FIX_README.txt describes the existing 2.0.1 map-loader repair.
