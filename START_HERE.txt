SKYMOTION 2.0.5 — FREE SKY NAVIGATION

1. Open the supplied pull request while signed into GitHub as ash-lava.
   Select Merge pull request, then Confirm merge.

2. Let Render deploy main automatically, or use:
   Render Dashboard > SkyMotion > Manual Deploy > Deploy latest commit.
   No new package, API key or environment setting is needed beyond 2.0.4.

3. Check https://skymotion-sk2p.onrender.com/api/health for version 2.0.5.
   Hard-refresh the website after deployment.

4. Open Sky atlas, or use:
   https://skymotion-sk2p.onrender.com/?mode=atlas

   - Drag anywhere to explore beyond the selected object.
   - Scroll/pinch or use +/- to zoom. All sky shows the complete sphere.
   - Enter any valid RA/Dec under Go to any RA / Dec.
     RA: 0 up to, but excluding, 360 degrees. Dec: -90 through +90 degrees.
   - Choosing coordinates or a suggested place preserves the atlas zoom.
   - The selected SPHEREx patch is a marker, not a limit on map coverage.
   - Use this sky position selects the map center for an exposure search.
   - Return to selected patch recenters the map without changing its zoom.
   - Share patch preserves the map's actual center and zoom.

The map location/zoom and SPHEREx cutout are independent. Switching to the
sequence and back keeps the map where you left it. An all-sky overview does
not request a whole-sky SPHEREx cutout; exposure cutouts remain 1-12 arcmin.

All images come from live IRSA archive products. No fixed demonstration
field limits the map. External service failures remain possible; Retry map
retries a failed image. Some surveys show plate boundaries and uneven
backgrounds when viewed at very large scales.

See HOW_IT_WORKS.txt for the beginner guide and VALIDATION.txt for evidence.
